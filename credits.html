The English cheatsheet

This independent learning companion adapts selected concepts from the VIP Cheatsheet: Transformers & Large Language Models by Afshine Amidi and Shervine Amidi, provided in their CME 295 repository under the MIT license. Read the unchanged English source PDF.

The authors' Super Study Guide and course provide the full explanations. This is not an official Stanford website, Microsoft project or author-approved edition.

Website created by Jacob Florkowski (Microsoft). This is a personal learning project. The original cheatsheet and book remain the work of Afshine Amidi and Shervine Amidi.

Scope of this companion

The current companion presents selected English concepts, a nine-chapter preview and three illustrative demonstrations on a dedicated interactive illustrations page. It does not reproduce every detail of the cheatsheet or the book. Definitions are condensed paraphrases, with qualifications where the source is simplified, particularly around DPO, PPO and model-based judging.

The attention example computes real scaled dot-product attention over invented two-dimensional vectors. The temperature example samples from five fixed logits. The masked-diffusion example follows a scripted reveal schedule. None runs a trained language model or calls an AI API.

Each chapter also includes an original interactive diagram: token embeddings, an attention heatmap, next-token sampling, low-rank adapters, a reinforcement-learning loop, a KV cache, retrieval-augmented generation, an evaluation rubric or a masked-token sequence. These are teaching illustrations, not measured training runs, benchmark results or real model outputs. Their assumptions are stated alongside each diagram.

The nine chapter quizzes contain 108 original multiple-choice questions: 12 per chapter, combining concept recall, worked applications and reasoning about limitations. Every answer choice has an explanation. Question navigation preserves selections, results separate recall, application and reasoning, and a mistake-only practice round leaves the original chapter score unchanged. Answer review can show all questions or only mistakes.

These are informal knowledge checks, not official course assessments. Quiz progress is held only while the page is open, is cleared by a refresh and is never sent to a server. The authored questions and illustrative calculations are not real model measurements.

The original PDF remains unchanged and available for comparison. This static companion can be viewed locally or shared as a public demo; it does not modify the authors' repository or the Polish translation pull request.
